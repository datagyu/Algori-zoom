# SWEA 25052 등산로

사용자가 제공한 Python 풀이를 sourceCode template에 그대로 사용합니다. 로컬 파일 입력 설정과 문제 설명은 제외합니다.

- 모든 출발점에서 왼쪽·위·오른쪽·아래 순서로 가장 낮은 이동 후보를 찾습니다.
- 출발 칸을 포함하여 길이를 계산하며, 더 낮은 이웃이 없으면 종료합니다.
- 현재 경로, 이동 후보, 검사 중인 칸, 현재까지의 최장 경로를 표시합니다.
- 모바일과 데스크톱에서 공통 재생·입력 UI를 사용합니다.
- 첫 줄 T가 필요합니다. 3 ≤ N ≤ 10, 높이는 1~N²의 서로 다른 정수입니다.
- 시각화 한 번에 지도 최대 10개, 실행 단계 최대 250,000개를 지원합니다.

검증: 첨부 예제 출력 #1 2 / #2 11 / #3 5 일치. 추가 지도 40개(N=3·4·5·10)에서 원본 Python과 결과 일치. 잘못된 입력 7종, 모든 샘플, 재생·일시정지·다시 재생·끝 이동·재생바·홈 검색 확인. 화면 너비 320·360·375·390·430·768·1024·1280·1440px에서 가로 넘침 없음. Chromium에서 검증했으며 실제 모바일 기기 검증은 별도입니다.
