# 기존 응용 문제 12개 검증 (2026-10-08)

첨부 화면의 5656, 5209, 5208, 4202, 5207, 5205, 5204, 5203, 5202, 5201, 5188, 5189를 **현재 로컬 코드** 기준으로 검사했습니다.

## 결과

- 개별 샘플·전체 샘플 및 문제당 40개의 결정적 임의 입력, 총 **559개 테스트케이스**의 출력이 별도 기준 풀이와 일치했습니다.
- 실제 공통 코드 마크업 생성기를 사용해 Python 코드 앵커의 존재, 반복 앵커의 순서, 단계 매핑의 누락·덮어쓰기를 검사했습니다.
- 최소 생산 비용의 현재 배정 비용, 최소합의 현재 경로 합과 최적 경로 합, 전자카트의 현재 이동 비용과 사무실 복귀를 포함한 최적 경로 비용도 확인했습니다. 재귀 호출 직전 선택 비용과 현재 호출의 누적 비용은 구분해서 검사합니다.
- 입력 부족·남는 입력 거부를 확인했습니다.
- 로컬 HTTP 서버와 headless Edge에서 **1440px / 390px 각각 12개 페이지**의 다음 단계·코드 강조·끝으로·재생바·입력 오류 후 복구·자동 재생·일시정지·2배속·전체 샘플 출력을 검사했습니다. PC/모바일 출력이 일치하고, 페이지 가로 넘침과 JavaScript pageerror가 없었습니다.
- 최소 생산 비용 PC, 전자카트 모바일 캡처를 확인했습니다. 실제 휴대폰 및 GitHub Pages 배포 상태는 검사하지 않았습니다.

기준 풀이: 벽돌 제거 집합과 열별 재배치 후 완전 탐색, 공장 배정 비트마스크 DP, 정류장 최단 교환 DP, 식재료 부분집합 계산, 이진 탐색 방향 경로 검사, 내장 숫자 정렬, 독립 재귀 병합 횟수 계산, 카드 빈도 계산, 작업 부분집합 전수 검사, 컨테이너·트럭 매칭 전수 검사, 격자 DP, 순회 비트마스크 DP입니다.

## 재생 시간: 추가 개선이 필요한 부분

아래는 개별 샘플의 **기존 1배속 단계 간격 × (단계 수−1)**으로 계산한 시간 범위입니다. 전체 자동 재생을 실시간으로 끝까지 기다린 측정값은 아니며, 렌더링·계산 비용에 따라 실제 재생은 더 길 수 있습니다. 여러 케이스가 포함된 `전체 샘플`은 제외했습니다.
