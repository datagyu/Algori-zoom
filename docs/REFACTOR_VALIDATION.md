# 리팩터링 검증 기록

기준: `2afad7a` (master, 리팩터링 시작 시점). 실행 환경: Linux Chromium 152, Playwright, 한국어 글꼴 설치. 제품에 테스트 도구·빌드 의존성을 추가하지 않았습니다.

## 화면 비교

홈, 1218, 2001, 5356을 각각 너비 1440 / 1280 / 1024 / 768 / 430 / 390 / 375 / 360, 높이 900에서 원본과 수정본으로 열었습니다.

- 32개 페이지/너비 조합에서 콘솔 오류 없음, 페이지 전체 가로 스크롤 없음.
- 공통 DOM 요소의 위치·크기·글꼴·padding·margin·색상 비교에서 차이 없음. 새 안내 요소와 생성된 코드 토큰 내부 markup은 비교 대상에서 제외했습니다.
- 1440/390의 전체 페이지 스크린샷을 생성하고 desktop/mobile 레이아웃을 검토했습니다.
- 홈의 안내문 제거, 문제별 title, 접근성 이름/키보드 focus 개선은 의도된 변경입니다.

## 알고리즘 및 컨트롤

| 문제 | 샘플 수 | 원본과 전체 비교한 step 수 | 확인한 특수 상태                        |
| ---- | ------: | -------------------------: | --------------------------------------- |
| 1218 |       2 |                      1,530 | push/pop/top, 괄호 강조, 실패/성공 결과 |
| 2001 |       2 |                        609 | swatter/current/best, 누적합, max_value |
| 5356 |       2 |                        480 | row/column, skip, 결과 문자열, chapter  |

샘플의 전체 단계 데이터는 원본과 동일합니다. 사용하지 않는 1218 `stopped` 필드만 비교에서 제외했습니다. 코드 줄 번호도 일치합니다. 시작·중간·마지막 및 초기 세부 단계는 실제 timeline input 이벤트로 이동하며 DOM의 값·강조 class를 비교했습니다.

직접 입력 확인:

- 1218 `([{}])<>` → `1`
- 2001 5×5 전체 1, M=2 → `4`
- 5356 `A / BC / DEF / GHIJ / KLMNO` → `ABDGKCEHLFIMJNO`

공통 확인: 샘플 선택, 직접 입력, 잘못된 입력 안내, 이전/다음, 초기화, 자동 실행과 정지, 다시보기, 끝 이동, timeline. 1218/5356 속도 변경과 5356 chapter 이동도 확인했습니다. 가상 시계로 timer를 진행해 정지 후 단계가 바뀌지 않는지 확인했습니다.

모바일 430/390/375/360: 실제 이전/다음 버튼과 timeline 동작, 코드창 내부 스크롤, 좌우 버튼의 화면 내 배치, 끝까지 스크롤했을 때 마지막 콘텐츠가 플레이어 위에 표시되는지 확인했습니다.

홈: 카드 3개, 검색 및 검색 결과 없음, 문제 링크 이동, 안내문 미표시 확인.

## 유지한 차이와 남은 제약

- 기존 외형 차이는 공통 CSS의 classic/editor/compact 표시 옵션으로 보존했습니다. 디자인을 통일하는 작업은 별도 범위입니다.
- 1218/2001은 첫 step, 5356은 READY부터 표시합니다. 2001 다시보기는 초기화이며 1218/5356은 재생을 시작합니다.
- Python 표시는 경량 토큰 강조이며 실제 Python 실행기가 아닙니다. 1218의 기존 한국어 의사코드 줄도 보존했습니다.
- sourceSteps는 줄 삽입에 안전하지만, 연결 대상 코드 내용 변경 시 text anchor도 수정해야 합니다.
- 홈 catalog와 정적 HTML의 문제 정보는 문제 설정과 별도로 존재합니다. 빌드 없이 정적 콘텐츠를 유지하기 위한 중복이며 추가 가이드에 동기화 항목을 명시했습니다.
- 모바일의 입력/샘플/자동 실행 UI 노출 범위는 기존 그대로 유지했습니다.
- 실제 iOS Safari/Android 기기 검증은 수행하지 않았습니다. 이번 검증은 Chromium의 viewport 변경 기준입니다.
