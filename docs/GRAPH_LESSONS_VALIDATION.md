# 응용 06·07 그래프 시각화

## 추가 범위

`88afy-algorithm/응용`의 실행 가능한 풀이를 기준으로 10966, 24220, 5247, 5248, 5249, 5251을 추가했습니다. 제목만 있는 5250은 제외했습니다. 원본 풀이에서 로컬 `sys.stdin` 설정, 주석 처리된 다른 풀이와 문제 설명을 제거했고, 5248의 디버그 `print(groups)`는 학습 코드에서 제거했습니다. 알고리즘은 각각 다중 시작점 BFS, DFS 백트래킹, BFS, union-find, 크루스칼, heapq 다익스트라입니다.

기존 theme/visualizer/UI와 코드 줄 연결 유틸리티를 사용합니다. 새 문제끼리 공통인 입력 검사·재생·화면 표현은 `assets/graph-lesson*.js`와 `assets/graph-lesson.css`에 있습니다. 기존 문제의 실행 코드는 수정하지 않았습니다.

## 코드 흐름을 따라가는 재생 (2026-10-08 수정)

- 10966: 물 검사 → 큐 추가 → 거리 0 → 큐에서 꺼내기 → 다음 좌표 → 조건 검사 → 거리 갱신 → ans 합산 → 큐 추가를 분리합니다. 12칸 이하 지도는 모든 칸을 상세히 보여줍니다. 큰 지도는 초기 땅 검사와 처음 두 칸 이후의 BFS 반복을 명시적으로 요약합니다.
- 5247: 처음 세 수에서 목표 검사, 네 연산 후보, 범위·방문 검사, 거리 기록, 큐 추가를 한 줄씩 보여줍니다. 이후의 같은 BFS 작업은 거리 층별로 요약하되 목표 조건과 break는 따로 보여줍니다. 긴 탐색은 20개 층씩 묶고 마지막에 최단 경로를 표시합니다.
- 24220: 기본 샘플은 모든 경로를 상세히 추적합니다. 방문 표시 직후에는 아직 재귀 호출 스택이 늘어나지 않고, 함수에 들어가면 스택이 늘어납니다. return 직후의 방문 표시는 True로 남아 있으며 호출한 함수에서 False로 복구합니다. 큰 그래프는 처음 두 완성/막다른 분기 이후의 반복을 재귀 호출·복귀 경계에서 요약하며 모든 경로를 셉니다.
- 5248: union에서 find로 들어가 부모 조건, 부모로 재귀, 대표 반환, 경로 압축을 추적합니다. 최종 대표를 집합에 넣는 과정도 사람마다 보여줍니다.
- 5249: 간선 후보 → 대표 비교 → union → 부모 연결 → ans 합산 → cnt 증가 → 종료 조건을 각각 표시합니다. 첫 find와 처음 부모를 따라가는 find는 함수 안으로 들어가며 이후의 같은 find는 반환된 대표를 비교 단계에 보여줍니다. 화면 상태를 만드는 함수는 부모 배열을 변경하지 않습니다.
- 5251: 큐 꺼내기, 오래된 후보 조건, continue, 다음 도로, new_w 계산, 거리 비교, distance 갱신, 큐 추가를 분리합니다. 거리 갱신 시점에는 새 후보가 아직 큐에 들어 있지 않습니다.

기본 간격은 단계당 1.1초입니다. 기본 샘플은 이제 32~87단계로, 간격 기준 약 34~95초입니다. 속도를 올리기 위해 중요한 상태 변경을 합치지 않습니다. 이전/다음, 재생바, 끝으로, 다시 재생, 0.5~2배속을 유지했습니다. 현재 코드 줄의 지역 변수와 배열, 큐 또는 호출 스택을 PC·모바일에 함께 표시합니다. 큰 입력의 반복을 요약할 때는 표시와 설명으로 구분합니다. 5247의 시작·목표 수는 학습용 1~2,000이며 중간 결과는 원래와 같은 1~1,000,000입니다.

## 검증 (2026-10-08)

`node tests/graph-lessons.cjs`:

- 18개 샘플 및 결정적 임의 입력을 포함해 343개 정답 비교 통과.
- 기준 풀이는 맨해튼 거리, 부분집합 DP 경로 수, 연결 요소 수, Prim, Bellman-Ford 및 연산 그래프의 반복 완화 방식입니다.
- 모든 단계의 Python 코드 앵커와 입력 부족·남는 입력·물 없는 지도·연결되지 않은 최소 비용 그래프 검사 통과.
- 거리 갱신 전후의 값, 거리 갱신과 큐 추가 사이의 상태, DFS 호출 전후 스택 크기와 used 복구, 경로 수 증가, find의 재귀·압축, MST 비용과 간선 개수의 별도 증가, 다익스트라의 같은 거리 후보와 오래된 후보를 검사했습니다.
- 5247의 긴 감소 예시(2,000 → 1)는 처음 세 확장을 보존하면서 120단계 미만인지 확인했습니다. 단계 수를 줄여 정답 계산을 중단하는 방식은 사용하지 않습니다.

`node tests/graph-lessons.cjs --browser`:

- JavaScript pageerror 없음. 5251 PC / 10966 모바일 캡처를 눈으로 검토했습니다.
- 실제 휴대폰 및 배포 사이트 검사는 수행하지 않았습니다.

브라우저 검사는 별도 Playwright와 Chromium 설치가 필요합니다. 설치된 런타임을 사용할 때는 `ALGORIZOOM_PLAYWRIGHT`(모듈 경로), `ALGORIZOOM_BROWSER`(브라우저 실행 파일)를 설정할 수 있습니다. 일반 정답 검사는 Node.js만 필요합니다.
