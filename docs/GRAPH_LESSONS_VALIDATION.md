# 응용 06·07 그래프 시각화

## 추가 범위

`88afy-algorithm/응용`의 실행 가능한 풀이를 기준으로 10966, 24220, 5247, 5248, 5249, 5251을 추가했습니다. 제목만 있는 5250은 제외했습니다. 원본 풀이에서 로컬 `sys.stdin` 설정, 주석 처리된 다른 풀이와 문제 설명을 제거했고, 5248의 디버그 `print(groups)`는 학습 코드에서 제거했습니다. 알고리즘은 각각 다중 시작점 BFS, DFS 백트래킹, BFS, union-find, 크루스칼, heapq 다익스트라입니다.

기존 theme/visualizer/UI와 코드 줄 연결 유틸리티를 사용합니다. 새 문제끼리 공통인 입력 검사·재생·화면 표현은 `assets/graph-lesson*.js`와 `assets/graph-lesson.css`에 있습니다. 기존 문제의 실행 코드는 수정하지 않았습니다.

## 짧은 재생

- 10966: 모든 물을 큐에 넣은 뒤 동일 거리의 새 땅을 한 단계로 묶습니다.
- 5247: 첫 수의 확장은 자세히 표시하고 이후 BFS 거리 층을 요약합니다. 긴 탐색은 20개 층씩 묶습니다. 마지막에 최단 경로 하나를 표시합니다.
- 24220: 첫 도착 또는 첫 막다른 경로까지 자세히 표시하고, 방문 복구와 출발점의 분기별 전체 경로 수를 표시합니다. 모든 경로는 실제로 탐색합니다.
- 5248/5249/5251: 대표 병합·경로 압축, 간선 선택·사이클 제외, 거리 갱신·오래된 후보 제외 등 의미 있는 변화를 표시합니다.

기본 간격은 단계당 1.1초입니다. 기본 샘플은 4~15단계로, 첫 단계에서 마지막 단계까지 약 3~15초입니다. 이전/다음, 재생바, 끝으로, 다시 재생, 0.5~2배속을 지원합니다. 큰 입력을 잘라 잘못된 답을 보여주는 방식 대신 학습용 입력 범위를 화면에 명시하고 검사합니다. 5247의 시작·목표 수는 1~2,000이며 중간 결과의 허용 범위는 원래 풀이와 같은 1~1,000,000입니다.

## 검증 (2026-10-08)

`node tests/graph-lessons.cjs`:

- 18개 샘플 및 결정적 임의 입력을 포함해 343개 정답 비교 통과.
- 기준 풀이는 맨해튼 거리, 부분집합 DP 경로 수, 연결 요소 수, Prim, Bellman-Ford 및 연산 그래프의 반복 완화 방식입니다.
- 모든 단계의 Python 코드 앵커와 입력 부족·남는 입력·물 없는 지도·연결되지 않은 최소 비용 그래프 검사 통과.
- 5247의 학습용 최장 감소 예시(2,000 → 1)도 30단계 미만인지 확인했습니다.

`node tests/graph-lessons.cjs --browser`:

- 로컬 HTTP 서버와 headless Edge에서 1440px / 390px로 6개 문제 모두 검사했습니다.
- 다음 단계, 코드 강조, 전체 샘플 출력, 재생바 이동, 잘못된 입력 후 정상 샘플 복구, 자동 재생, 일시정지, 재생 속도 변경, 가로 넘침 검사 통과.
- JavaScript pageerror 없음. 5251 PC / 10966 모바일 캡처를 눈으로 검토했습니다.
- 실제 휴대폰 및 배포 사이트 검사는 수행하지 않았습니다.

브라우저 검사는 별도 Playwright와 Chromium 설치가 필요합니다. 설치된 런타임을 사용할 때는 `ALGORIZOOM_PLAYWRIGHT`(모듈 경로), `ALGORIZOOM_BROWSER`(브라우저 실행 파일)를 설정할 수 있습니다. 일반 정답 검사는 Node.js만 필요합니다.
